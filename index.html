Selected work

Each of these ran end to end: data in, model or agent in the middle, something a person can act on at the other end.

Build Agent Tunisia — a voice agent that speaks Tunisian Derja

A conversational agent for customers who don't want to switch to French or Modern Standard Arabic to be understood. Speech-to-speech and text-to-speech pipelines feed an LLM reasoning layer orchestrated with LangChain, grounded in a RAG knowledge base so answers stay accurate rather than fluent-and-wrong. The hard part was the dialect: little clean data, code-switching everywhere, and no off-the-shelf benchmark to hide behind.

  • LangChain
  • RAG
  • Speech-to-speech
  • TTS
  • Tunisian dialect NLP
  • Agentic AI

Smart Marketing Intelligence Platform

Turns raw marketing data into written insight with no manual reporting step. I built the foundation — Airflow for orchestration, dbt for transformation, ClickHouse as the analytical warehouse — then layered an LLM agent that reads the modeled data and drafts the report. Dashboards for stakeholders, Langfuse traces for me.

  • Airflow
  • dbt
  • ClickHouse
  • LLM agents
  • LangChain
  • Langfuse

Taxi booking fraud detection

End-to-end pipeline for a simulated ride-hailing platform: ingest booking, driver, payment and trip data, engineer behavioural and transaction-level features, then score for anomalies. Designed for both batch backfills and real-time scoring, with monitoring so detection drift surfaces before the business notices it.

  • Spark
  • Kafka
  • Feature engineering
  • Anomaly detection
  • Real-time scoring

Real-time analytics for healthcare signals

A distributed pipeline for predictive health analytics: Kafka for streaming ingestion, Spark for large-scale processing and heart-attack risk prediction, Druid for low-latency OLAP, Superset for the dashboards clinicians actually open.

  • Kafka

MLOps pipeline for movie rating prediction

Built to remove every manual step from the model lifecycle: DVC for versioned data and models, MLflow for experiment tracking, Docker for deployment, Jenkins for CI/CD. A new model ships the same way twice.
